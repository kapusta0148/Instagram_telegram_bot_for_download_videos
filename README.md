# 📥 Social Media Video Downloader Bot

Telegram-бот, который позволяет скачивать видео из **Instagram**,
**YouTube** и **ВКонтакте** всего по одной ссылке.\
Простой, быстрый и удобный инструмент для загрузки медиа напрямую в
Telegram.

## 🚀 Возможности

-   📌 Скачивание видео по ссылке:
    -   Instagram Reels / Posts\
    -   YouTube (короткие и длинные видео)
    -   VK (видео с любых публичных страниц)
-   🤖 Удобное взаимодействие --- бот сам подсказывает, что делать\
-   🔐 Секретные ключи и сообщения вынесены в `.env` файлы\
-   🧩 Возможность расширения списка платформ

## 🗂️ Структура проекта

    project/
    │
    ├── main.py              # Запуск бота, хендлеры Telegram
    ├── dotenv_func.py       # Функция загрузки .env файлов
    ├── text.env             # Текстовые сообщения для бота
    ├── keys.env             # Ключи и токены
    ├── requirements.txt
    └── README.md

# 🎨 Концепция оформления бота

Бот оформлен в стиле **минимализма и удобства**:

-   цветовая палитра сообщений:
    -   🩵 голубые подсказки\
    -   💛 дружелюбные приветствия\
    -   ⚪ лаконичный текст

Примеры сообщений:

**Приветствие:**

    👋 Привет, <имя>!
    Отправь мне ссылку на видео из Instagram, YouTube или VK — и я загружу его для тебя.

**Ошибка:**

    ⚠️ Я не смог распознать ссылку.
    Проверь, что ты отправил правильный URL!

**Обработка:**

    🎬 Обрабатываю твою ссылку...
    ⏳ Пожалуйста, подожди пару секунд

**Готовое видео:**

    ✅ Готово! Вот твоё видео 👇

# 🧠 Логика общения бота с пользователем

1.  `/start` → приветствие\
2.  Пользователь отправляет ссылку\
3.  Бот определяет тип платформы\
4.  Бот сообщает о начале обработки\
5.  Отправка видео или понятная ошибка
